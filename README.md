# 🎬 Movie Ticket Management System

## 📌 About the Project

The **Movie Ticket Management System** is a Pega-based application designed to simplify and automate the movie ticket booking process.

The system allows users to browse movies, select show timings, choose seats, and manage their ticket bookings through a simple workflow.

## 🎯 Objectives

* Simplify the movie ticket booking process
* Manage movies and show timings
* Allow users to select available seats
* Maintain customer and booking details
* Automate the booking workflow using Pega

## 🚀 Features

* 👤 User Management
* 🎥 Movie Management
* 🕐 Show Timing Management
* 💺 Seat Selection
* 🎟️ Ticket Booking
* 📋 Booking Management
* 📊 Booking Status Tracking

## 🛠️ Technologies Used

* **Pega Platform**
* Pega App Studio
* Pega Case Management
* Pega Data Objects
* Pega UI
* Workflow Automation

## 🔄 Workflow

```text
Login
  ↓
Select Movie
  ↓
Select Show
  ↓
Select Seats
  ↓
Enter Details
  ↓
Confirm Booking
  ↓
Ticket Booked
```
